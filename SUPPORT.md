# Support

Before requesting help:

1. Read the relevant sections of `README.md`.
2. Confirm that you are using Windows x64 and Windows PowerShell 5.1 or newer.
3. Record the application version, selected action, exact error message, and steps to reproduce.
4. Remove usernames, access tokens, private paths, and other personal or sensitive information from logs.

Use GitHub Issues for reproducible bugs and feature requests. Do not use public issues to report security vulnerabilities; follow `SECURITY.md` instead.

This is an independent community utility. For issues with the OpenCode CLI itself, consult the official OpenCode project and its support channels.
